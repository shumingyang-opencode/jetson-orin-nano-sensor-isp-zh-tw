I2C 與感測器位址

Orin 上的感測器經 I2C 控制（GMSL 時透過 deserializer 的 I2C 通道）。OV9281 常見 7-bit 位址 0x36。

掃描感測器 I2C
sudo i2cdetect -y <总线>              # 依 DTB 的 i2c 匯流排
sudo i2cget -y 0 0x36 0x300a          # 讀 OV9281 ID 高位
