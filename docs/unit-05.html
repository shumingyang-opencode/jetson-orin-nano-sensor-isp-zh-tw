Argus 拍照與預覽

argus_camera
argus_camera --mode 0 --capture-auto 1 --duration 1
argus_camera --preview 1 --mode 0
第一步驗證：argus_camera 能出圖 = 感測器→tegra ISP→輸出整條鏈路通。後續調校才有意義。

V4L2 / GStreamer

v4l2-ctl 與 gst
v4l2-ctl -d /dev/video0 --set-fmt-video=width=1280,height=720,pixelformat=NV12
gst-launch-1.0 v4l2src device=/dev/video0 ! videoconvert ! autovideosink
看完這單元你應該能說出：
  • 用 argus_camera 拍照/預覽。
  • 用 v4l2-ctl / GStreamer 取流。
  • 「出圖 = 鏈路通」的驗證。
  • Argus vs V4L2 的取流差異。
