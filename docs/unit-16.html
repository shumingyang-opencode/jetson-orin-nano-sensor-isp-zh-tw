GMSL 多相機

Orin 可透過 GMSL deserializer（MAX96712，多 link）接多顆遠距離感測器，每顆有獨立 I2C 通道與 lock 狀態。

GMSL 除錯重點：① 每條 link 的 I2C 通道 ② serdes 是否 lock ③ DTB 每個 camera 節點。

完整案例：Orin 調校一顆 OV9281

  1. DTB 宣告感測器 + serdes 節點。
  2. 確認 probe 成功、Argus 列舉到相機。
  3. argus_camera 出圖 → 確認 AE/AWB 自動收斂。
  4. RAW 分析：黑位、缺陷像素、雜訊。
  5. NVIDIA 工具做 LSC / 色彩基準。
  6. 不同場景回歸。

最佳實踐

  • 固定測試場景，量化比較。
  • 讓 NVIDIA AE/AWB 自動化收斂，只干預異常。
  • 多感測器逐顆驗證、逐顆獨立 LSC。
  • 記錄每次改動與前後圖。

16.4 深入：客製 OV9281 接入的檢查清單

checklist
□ 硬體：CSI lane / I2C / reset / clock
□ DT overlay：compatible / reg / clocks / reset-gpios
□ 驅動：現成 or 改 init table
□ dmesg：probe 成功？讀到 ID？
□ 出圖：能取到幀？
□ RAW：Bayer order / 黑位 / 缺陷像素
□ 調校：黑位 → LSC → AWB/CCM → NR/Sharpen
紀律：一次只換一個變數，保留官方模組當對照組。
