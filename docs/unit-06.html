檢查項驗證

GMSL serdes 除錯

GMSL 關鍵：感測器資料要經過 deserializer（如 MAX96712）。常見問題：① deserializer 的 I2C 通道沒切到對的 link ② serdes 鎖定失敗 ③ DTB 沒宣告 serdes 節點。先用 vendor 工具確認 serdes lock。

用 dmesg 追線索

除錯指令
dmesg | grep -i -E "ov9281|tegra-camera|vi5|csi"
cat /sys/kernel/debug/bpmp/debug/clk/...   # 檢查 clock
看完這單元你應該能說出：
  • Bring-up 四件事。
  • GMSL serdes 的 I2C 通道與 lock。
  • 用 dmesg 追 tegra-camera 錯誤。
  • 「argus 列不到相機」的排查。
