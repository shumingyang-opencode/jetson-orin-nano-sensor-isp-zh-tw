Bring-up 四件事

檢查項驗證
電源AVDD/DVDD 到位、時序
ClockMCLK 輸出、PLL 鎖定
I2Ci2cdetect（GMSL 先打通 deserializer）
MIPIdmesg 無 CSI 錯誤、argus 列舉

GMSL serdes 除錯

GMSL 三步：① deserializer I2C 通道切到對的 link ② 確認 serdes lock ③ 感測器 I2C 才可通。先用 vendor 工具確認 lock，再談感測器。

Register dump 實作

透過 tegracam controls
v4l2-ctl -d /dev/v4l-subdev0 -C exposure
v4l2-ctl -d /dev/v4l-subdev0 -C analogue_gain

Bring-up 決策樹

「argus 看不到相機」決策樹
1. dmesg 有 tegra-camera/感測器 probe？
   ├─ error → DTB / 電源 / serdes
   └─ ok ─┐
2. (GMSL) serdes lock？
   ├─ 否 → deserializer / 線材 / 通道
   └─ 是 ─┐
3. i2cdetect 讀到感測器 ID？
   ├─ 否 → I2C 通道 / 位址
   └─ 是 ─┐
4. argus_camera 出圖 → ✅

  • Bring-up 四件事。
  • GMSL serdes 三步。
  • register dump 實作。
  • 照決策樹排解。
