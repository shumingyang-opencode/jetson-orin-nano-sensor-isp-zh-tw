RAW 與處理後格式

格式說明
NV12 / YUVISP 處理後（多數應用）
SRGGB10 / Bayer RAW感測器原始資料（調校分析用）

Argus 取 RAW

argus 指定 raw 輸出（示意）
argus_camera --mode 0 --raw-file out.raw --duration 1

RAW 擷取是影像品質分析的基礎——雜訊、黑位、色彩都要回到 RAW 看。

Bayer order 與位元深

陷阱：Bayer order 設錯 → 全色錯；位元深與後處理格式不符 → 暗部階調損失。設定 RAW 前先確認感測器 datasheet 的 Bayer 起點。

  • Argus 取 RAW 的方式。
  • Bayer order 陷阱。
  • RAW 在調校分析的角色。
