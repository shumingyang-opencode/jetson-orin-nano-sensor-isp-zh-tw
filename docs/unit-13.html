NVIDIA 的降噪

  • 空間 + 時間降噪，自動化程度高。
  • 深度調校需 NVIDIA 工具。
取捨紀律：先確認感測器增益沒拉太高（源頭），再讓 ISP 降噪收尾。

13.6 雜訊預算（Worked Example）

判斷「補光還是接受雜訊」
# 目標 SNR >= 30dB（σ/S < 3.2%）
# gain 高時量測：σ=20, 訊號=400
SNR = 20*log10(400/20) = 26 dB   # 不達標
# 補光 + 降增益：訊號 800, σ≈18 → SNR 33 dB ✓
# 結論：補光 + 降增益 優於 硬拉增益
工程判斷：用 SNR 預算量化，先定可接受的 SNR，再決定曝光/增益/補光組合。

13.7 DPC 與 NR 順序

  • DPC 先：修缺陷像素（否則 NR 把亮點擴散成亮斑）。
  • NR 後：處理統計性雜訊。
  • 驗證：黑框 RAW 的 max 應被壓制。
看完這單元你應該能說出：
  • 四種雜訊來源。
  • NVIDIA 空間+時間降噪。
  • 「先源頭後收尾」策略。
  • 降噪與細節取捨。
