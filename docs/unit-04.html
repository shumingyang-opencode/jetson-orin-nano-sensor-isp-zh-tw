tegracam 驅動框架

NVIDIA 用 tegracam（camera sensor framework）承接感測器驅動，統一曝光/增益等 controls，並讓 Argus 能列舉相機。

  • 感測器驅動（如 OV9281）繼承 tegracam 介面。
  • 每個感測器在 DTB 宣告一組「camera 節點」。

DTB overlay：宣告感測器

DTB 感測器節點（示意）
&ov9281_cam0 {
    status = "okay";
    reg = <0x36>;        # I2C 位址
    reset-gpios = ...;    # RESET 腳位
};

修改 DTB 需重新編譯 device tree 並刷入（或放 bootloader overlay）。

Argus 如何看到相機

列出相機
argus_camera --list-cameras
v4l2-ctl --list-devices
調校關鍵：Argus 透過感測器驅動的 controls（曝光、增益）與 NVIDIA ISP 配合——驅動註冊正確，Argus 才看得到相機。
看完這單元你應該能說出：
  • tegracam 在 NVIDIA 相機堆疊的角色。
  • DTB 感測器節點宣告方式。
  • Argus 如何列舉相機。
  • 驅動→Argus→ISP 的關係。
