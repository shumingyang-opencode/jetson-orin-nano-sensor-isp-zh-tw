為什麼要懂子版本：Jetson 系列以模組區分運算等級；Orin Nano 是最入門的 AI 邊緣模組，但感測器/相機能力一致（CSI + GMSL）。

子版本比較

版本SoCRAM關鍵 I/O適合開發
Orin Nano（8GB）Ampere GPU + A78AE8GBCSI、GMSL 支援入門 AI 邊緣、影像
Orin Nano SuperAmpere GPU8GB同 Nano，更高 TOPS生成式 AI、視覺
Orin NX（16GB）Ampere GPU16GBCSI、GMSL中階多感測器
Orin AGX（64GB）Ampere GPU64GB全 I/O高階、大模型

配件與外設

配件說明 / 用途
Jetson Camera ModuleIMX219/477 等官方相機模組
GMSL 相機（serdes）MAX96712 deserializer + 遠距離相機
Arducam 等第三方依 DTB overlay 相容性

選擇建議

  • sensor 調校開發：Orin Nano 即可，介面與高階模組一致。
  • 多感測器/量產 → 視相機路數選 NX/AGX。

  • 依需求選擇版本的判斷依據。
